Web Installer

デスクトップ版Chrome / Edgeから、USB経由で書き込めます。使用するXIAOボードを選択してください。

このブラウザーはWeb Serialに対応していません。PCのChromeまたはEdgeで開いてください。

  1. データ通信対応USBケーブルでXIAOを接続します。
  2. 「インストールする」を押し、XIAOのシリアルポートを選びます。
  3. 画面の案内に従って書き込み、完了後にRESETを押します。

接続できない場合は、シリアルモニターやDAWを閉じ、BOOTを押しながらUSBを接続してからBOOTを離してください。特にS3のUSB MIDI動作中は、この方法でダウンロードモードへ切り替えられます。

既存のファームウェアを置き換えます。「消去」を選ぶと保存済み設定やBLEペアリング情報も削除されます。元のChainOSCPadから切り替える場合は、必要な設定を事前にエクスポートしてください。

インストール後の使い方

12キー同時押しチャンネル1Note 60–71Velocity 100
  • S3 / USB：DAWでChainOSCPad MIDIの入力ポートを選びます。
  • 全ボード / BLE：Bluetooth MIDI対応アプリからChainOSCPad MIDIへ接続します。
  • エンコーダー：回転はCC1（Modulation）、押しボタンはCC64（Sustain）。

Windowsでは対応するBLE-MIDIドライバー／アプリが必要です。EdgeのWeb MIDIで入力が見つからない場合は、Bluetooth接続後にedge://restartでEdgeを再起動してください。本プロジェクトではKORG BLE-MIDI Driver 1.16系とEdgeで、この手順によるデバイス認識を確認しました。

S3でUSBとBLEの両方を同じ音源へ入力すると二重発音するため、DAW側で使用する入力を選択してください。
